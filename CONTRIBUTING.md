# Contributing

Thank you for improving Cockpit TSPI Theme.

## Before opening an issue

Please include:

- Linux distribution and version
- Cockpit version from `cockpit-bridge --version`
- Browser and version
- A screenshot of the affected page
- Relevant browser console errors

## Pull requests

1. Keep changes focused on presentation.
2. Preserve keyboard accessibility and visible focus states.
3. Test both light and dark color schemes.
4. Test desktop and a viewport around 390 px wide.
5. Run `sh scripts/package.sh` before submitting.
6. Update `CHANGELOG.md` for user-visible changes.

Do not include private hostnames, IP addresses, serial numbers, machine IDs, credentials, or personal screenshots in commits.
